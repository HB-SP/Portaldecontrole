COMO TROCAR OU ACRESCENTAR
--------------------------
1. Ponha o arquivo original em ../../logos-originais/ (fica na máquina, não vai
   para o ar).

2. Prepare: logo oficial vem grande demais, com margem enorme e às vezes com
   fundo branco chapado. O script resolve os três de uma vez:

     node scripts/preparar_logo.mjs logos-originais/X.jpg public/campeonatos/x.png --tirar-fundo
     node scripts/preparar_logo.mjs logos-originais/X.png public/campeonatos/x.png --placa A104F0

   --tirar-fundo é para JPG (que não tem transparência).
   --placa RRGGBB é para logo em versão branca.

3. Aponte no banco:

     MSYS_NO_PATHCONV=1 node scripts/logo_campeonato.mjs brasileirao /campeonatos/brasileirao.png

   O MSYS_NO_PATHCONV=1 é por causa do Git Bash, que senão troca o "/" do
   começo por um caminho do Windows e grava um endereço quebrado. O script
   avisa quando isso acontece.

Para tirar:   node scripts/logo_campeonato.mjs brasileirao --tirar
Para listar:  node scripts/logo_campeonato.mjs

COMO O CARD MOSTRA
------------------
Altura fixa de 42px, largura livre até 132px. Escudo quadrado fica quadrado;
assinatura deitada ocupa a largura que precisa. Sem logo, o card usa as
iniciais do campeonato na cor dele — nunca fica buraco.
